# For My Dearest Abhinaya ❤️

A romantic, interactive scrapbook & birthday surprise built for Abhinaya — designed to work seamlessly on phones (iPhone & Android), tablets, laptops, and desktops.

## 🌐 Open on Phone & Other Devices

Once GitHub Pages is enabled in repository **Settings → Pages → Source: GitHub Actions** (or **Deploy from a branch: `main`**), the site is live at:

**https://nandyalarameshsomraj-eng.github.io/abhinaya/**

### 📱 Install as an App on Your Phone
- **iPhone / iPad (Safari):** Open the link → tap the **Share** button (`□↑`) → tap **Add to Home Screen**.
- **Android (Chrome / Samsung Internet):** Open the link → tap **⋮ Menu** → tap **Add to Home screen** / **Install app**.
